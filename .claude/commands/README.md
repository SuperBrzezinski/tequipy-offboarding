# Slash commands

Mechanical triggers for the most common procedures. `:::meta` (message prefix) is the primary
way to enter META mode; `/meta` is a reliable alias.

| Command | Does |
|---------|------|
| `/meta [focus]` | Enter META mode (alias for `:::meta`) — improve the agent itself. |
| `/checkpoint` | Persist memory + emit git block + suggest clearing chat. |
| `/breakdown [epic]` | JIT-break the active epic into tasks. |
| `/discovery` | Run the discovery session before the spec. |
| `/adr <title>` | Create or supersede an ADR. |
| `/review` | Independent read-only code review of the current diff. |
| `/status` | Print current state from memory (read-only). |
